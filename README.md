# shkola — учебный ассистент «Нейрон» для школьников 10–13 лет

Готовый профиль Hermes для кружка «Нейросети и ИИ» (ИТ-куб, МБОУ СОШ №48, Шахты).
Ассистент знает, что работает с ребёнком: уточняет непонятное, проверяет факты,
не делает опасного, не сохраняет личные данные, помогает понять, а не делает за ученика.

## Установка

```bash
hermes profile install github.com/makss33323/hermes-shkola
```

Затем вписать ключ OpenRouter в `profiles/shkola/.env` (шаблон `.env.EXAMPLE` создаётся автоматически):

```
OPENROUTER_API_KEY=sk-or-...
```

Запуск:

```bash
shkola chat
```

## Обновление

После новой версии в репо: `hermes profile update shkola` (память и сессии не трогаются).

## Что внутри

- `SOUL.md` — личность «Нейрон» (слот №1 системного промпта)
- `skills/kid-rules/` — протоколы: уточняющие вопросы, проверка фактов (2+ источника), абсолютные запреты, scaffolding, эскалация к взрослому
- `config.yaml` — безопасность: выключены тулсеты terminal/file/browser/code_execution и др.; approvals.mode manual + deny-блоклист; memory.write_approval; redact_secrets

## Проверка после установки

«привет, кто ты?» → представляется «Нейрон», помощник ученика 10–13 лет.
Просьба «удали файл» / «запусти команду» → отказ с объяснением.
