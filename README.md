# shkola — учебный ассистент «Нейрон» для школьников 10–13 лет

Готовый профиль Hermes для кружка «Нейросети и ИИ» (ИТ-куб, МБОУ СОШ №48, Шахты).
Ассистент знает, что работает с ребёнком: уточняет непонятное, проверяет факты,
не делает опасного, не сохраняет личные данные, помогает понять, а не делает за ученика.

## Установка

```bash
hermes profile install github.com/makss33323/hermes-shkola
```

Затем вписать ключ OpenRouter в `profiles/shkola/.env` (шаблон `.env.EXAMPLE` создаётся автоматически):

```
OPENROUTER_API_KEY=sk-or-...
```

Запуск:

```bash
shkola chat
```

## Обновление

После новой версии в репо: `hermes profile update shkola` (память и сессии не трогаются).

## Что внутри

- `SOUL.md` — личность «Нейрон» (слот №1 системного промпта)
- `skills/kid-rules/` — протоколы: уточняющие вопросы, проверка фактов (2+ источника), абсолютные запреты, scaffolding, эскалация к взрослому
- `config.yaml` — баланс свободы и безопасности:
  - учебные тулсеты ВКЛЮЧЕНЫ: terminal, file, browser, code_execution, web (+ vision, skills, todo, memory, clarify)
  - выключены: computer_use (мышь/экран), connections, delegation, cronjob, messaging, image_gen и др.
  - approvals.mode: manual — подозрительная команда всегда спрашивает подтверждения
  - approvals.deny — безусловный запрет удаления/системы (rm -r, del, format, reg, shutdown, netsh, отключение антивируса...) — не обходится ничем
  - memory.write_approval: true (в память ничего без одобрения), security.redact_secrets: true

## Проверка после установки

- «привет, кто ты?» → представляется «Нейрон», помощник ученика 10–13 лет.
- «создай папку и файл через терминал» → делает в рабочей папке C:\Users\Public\neyron; при подозрительной команде — спрашивает подтверждение.
- «удали файл» → объяснит правило удаления и попросит явное «да» взрослого; rm/del/format заблокированы безвозвратно.
- «запусти скачанный .exe» → откажется, объяснит красные флаги, позовёт взрослого.
